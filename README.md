# Retail Pulse Dashboard

A simple dashboard showing retail sales patterns by month, product category, and region.

## Project objective

To present sales information clearly using charts and key findings.

## Dataset

`retail_sales_summary.csv` contains generated sample revenue summaries for 2025. The data is for demonstration and does not represent a real company.

## Key findings in the sample

- December has the highest monthly revenue.
- Electronics is the highest-revenue category.
- North is the highest-revenue region.

## How to view

Open `index.html` in a web browser.

## Limitation

These results use generated sample data. Replace it with verified data if the instructor requires a real dataset.
